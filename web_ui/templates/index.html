05 / ROBOT MIGRATION

核对电机能力与动作范围

直接填写电机转子惯量，关节传动比默认 1:1；有减速时修改 N，系统自动计算关节侧惯量。

电机输入 → 自动折算到关节

关节等效惯量 armature = 电机转子惯量 × 总传动比 N²。转子直接带关节时 N = 1，电机与关节惯量相同；3:1 减速填 N = 3，关节惯量为转子惯量的 9 倍。

只填写下表中的电机转子惯量和关节总传动比，自动计算结果为只读。修改后立即用于 PD 测试和生成的训练配置，不需要另点“应用 PD”才能让惯量生效。转子惯量未知时留空，保留原配置或模型假设并标注；不会将未知当作 0，也不从旧关节惯量反推电机参数。

仿真扭矩上限
填实机控制器实际允许的关节扭矩上限，可采用受驱动器、电流与机械限制后的峰值或降额值。若只允许持续额定扭矩，就填该值。当前仿真为固定限幅，没有峰值持续时间或热降额模型。
额定连续扭矩
下方补充表填相应工况下可持续输出的额定值，不填短时峰值；只作高级 PD 静态预算，不替换仿真限矩。
允许最高工作转速
下方补充表填当前供电、驱动器与机构允许的关节最高工作转速，不填额定转速。可选择 rpm 或 rad/s 填写，系统自动换算；只检查 PD 是否超速，不强制限速。
直驱 / 减速填写示例与单位 默认 N = 1（1:1）

直驱：电机转子惯量 0.0001 kg·m²，N = 1，自动得到关节惯量 0.0001 kg·m²。3:1 减速：同一转子填 N = 3，自动得到 0.0009 kg·m²。N = |转子转速 / 关节转速|，多级比相乘，例如内部 6:1、外部 2:1，总 N = 12。

惯量没有额定/峰值之分。这里填写裸电机转子轴惯量，不填连杆刚体惯量或已经折算到输出轴的惯量；单位 kg·m²。厂家给 g·cm² 时乘 10⁻⁷ 换算。其他旋转传动件的惯量不由单一转子公式自动建模，模型已包含的同一惯量不要重复计入。

此处 N 自动折算惯量；扭矩与转速仍填最终关节侧数值，不随 N 自动更改。裸电机能力可按 τ_joint ≈ η × N × τ_motor、ω_joint = ω_motor / N 换算后填写；η 是传动效率，惯量折算不乘 η。
